Mail Code Copy

Grab login and verification codes from your Fastmail inbox with one click — no need to open your email.

  1. In Fastmail, open Settings → Privacy & Security → Integrations
  2. Click New API token and choose read-only access
  3. Paste it below
Mail Code Copy is not affiliated with Fastmail. Your token stays in this browser and is only sent to Fastmail. The extension reads just the subject and text of new messages.
Folders to watch

Your Inbox is watched by default. Tick others if you have rules that file mail elsewhere.
