Mail Code Copy

Grab login and verification codes from your Fastmail inbox with one click.

Step 1 of 4

Create a Fastmail token

  1. Open Settings → Privacy & Security → Integrations in Fastmail
  2. Click New API token
  3. Choose read-only access to Mail, then create it and copy the token
Open Fastmail settings ↗
Step 2 of 4

Connect

Paste your token below.

Your token stays in this browser and is only sent to Fastmail. Mail Code Copy is not affiliated with Fastmail.
Step 3 of 4
